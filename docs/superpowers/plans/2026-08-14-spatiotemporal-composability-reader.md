# Spatiotemporal Composability Reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a standalone Atlas page that gives ordinary developers both a ten-minute interactive explanation and a complete, source-mapped guide to “A Programming Paradigm for Spatiotemporal Composability.”

**Architecture:** Build an isolated React 19 + Vite project under `projects/spatiotemporal-composability`. Keep paper-derived copy and page references in structured content data, model the teaching lab with a pure reducer, and compose focused presentational components around those two sources. The site is entirely local/static, links to a bundled PDF through `BASE_URL`, and is verified with Vitest, Testing Library, the Atlas root build, and desktop/mobile browser screenshots.

**Tech Stack:** React 19.1, Vite 7.1, Vitest 3.2, Testing Library 16.3, jsdom 26, CSS, inline accessible SVG, bundled PDF.

## Global Constraints

- The page is a new independent Atlas project at `projects/spatiotemporal-composability/`.
- The audience is ordinary developers; formulas and proof notes remain optional disclosures.
- The first reading layer must cover the paper in about ten minutes; the deep layer must cover motivation, preliminaries, mechanisms, calculus, metatheory, Cordis, Koishi, discussion, and limits.
- Clearly label paper claims, Cordis implementation facts, engineering analogies, and open questions.
- Use the bundled 88-page PDF and construct its URL with `import.meta.env.BASE_URL`.
- Use a paper-white/ink editorial layout, warm temporal accent, cool spatial accent, and no decorative dashboard-card grid.
- The lab is explicitly a teaching model, not a byte-for-byte Cordis simulator.
- No runtime network requests, external APIs, account state, comments, AI Q&A, or full-paper translation.
- Preserve non-JavaScript access to core explanatory copy and the PDF link through `<noscript>` content.
- Respect keyboard navigation, reduced motion, high contrast, and narrow-screen layouts.
